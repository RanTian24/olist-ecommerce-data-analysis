## 一、项目背景
本项目基于Olist巴西电商公开数据集，围绕电商平台的订单、客户、商品、支付以及物流等业务数据进行展开分析。
通过数据清洗、多表关联、指标计算和可视化分析，了解平台的销售情况、客户消费行为、商品类别表现以及订单履约情况，并从数据中发现潜在的经营问题，为业务运营决策提供参考。

## 二、数据来源
本项目使用Olist巴西电商公开数据集，公开托管发布在Kaggle。

数据集包含多个业务数据表，主要包括：

- 订单数据（orders）
- 客户数据（customers）
- 商品数据 （products）
- 订单数据明细（order_items）
- 支付数据（order_payments）
- 评价数据（order_reviews）
- 卖家数据（sellers）
- 地理位置数据（geolocation）
- 商品类别翻译数据（catefory_translation）

通过订单编号、客户编号、商品编号等字段，将不同数据进行关联，构建多维度分析数据集。

## 三、分析目标

本项目主要围绕以下目标展开：

1. 分析平台整体销售表现，了解订单、销售额以及客单价的变化趋势。
2. 分析客户消费行为，识别复购客户并评价不同客户群体的价值。
3. 分析商品类别表现，识别销售额和销售量较高的商品类型。
4. 分析支付方式，了解不同的支付方式的使用情况。
5. 分析订单履约情况，评估订单处理效率、配送时长以及物流延迟情况。

通过以上分析，识别平台经营中的优势与潜在问题，为业务运营提供数据参考。

## 四、分析内容

### 1. 数据读取与数据质量检查
- 使用 Pandas 读取多张 CSV 数据表。
- 检查数据表结构、数据类型及主外键关系。
- 分析缺失值、重复值及异常数据。
- 完成日期格式转换和数据预处理。

### 2. SQL 数据查询与多表关联
- 使用 SQLite 创建数据库并导入业务数据表。
- 使用 SELECT、WHERE、GROUP BY、ORDER BY 等语句进行数据查询。
- 使用 JOIN 完成订单表与商品明细表关联。

### 3. 订单与销售分析
- 分析订单状态及订单数量。
- 计算订单商品销售额及平均订单销售额。
- 分析月度订单量、销售额及客单价变化趋势。

### 4. 客户价值分析
- 统计真实用户购买次数及复购情况。
- 计算客户复购率。
- 基于 RFM 模型对客户进行价值分层。
- 比较不同客户层级的数量及消费金额贡献。

### 5. 商品类别分析
- 关联商品表、订单商品明细表及类别翻译表。
- 统计不同商品类别的销售额和销量。
- 分析商品类别销售额占比及销售集中程度。

### 6. 支付方式分析
- 统计不同支付方式的使用次数及支付金额。
- 分析不同支付方式的金额占比。
- 分析信用卡一次性支付与分期支付情况。

### 7. 订单履约与物流分析
- 分析订单状态及履约情况。
- 计算订单审核、交付物流及配送时长。
- 分析物流延迟率及延迟天数。

### 8. 数据可视化
- 客户价值分层及金额贡献图表。
- 月度订单量、销售额及客单价趋势图。
- 商品类别销售额 Top 10 图表。
- 物流配送时长分布及延迟情况图表。

## 五、核心分析结论

### 1. 销售表现
- 平台商品销售总额约为 1,359.16 万 BRL。
- 月度销售表现存在波动，部分月份订单量增长带动销售额提升。

### 2. 客户价值
- 客户复购率较低，多数客户只完成一次购买。
- 高价值及较高价值客户约占客户总数的 25.08%，贡献约 44.13% 的客户消费金额。

### 3. 商品类别
- 销售额排名前十的商品类别贡献约 63.20% 的商品销售额。
- 不同商品类别的销售额与销量排名并不完全一致。

### 4. 支付方式
- 信用卡贡献约 78.34% 的总支付金额。
- 在有效信用卡支付记录中，分期支付占约 66.85%。

### 5. 物流履约
- 有效配送订单的延迟率约为 8.11%。
- 配送时长分布存在明显长尾，部分订单配送时间较长。
